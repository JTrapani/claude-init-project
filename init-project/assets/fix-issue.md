---
name: fix-issue
description: Investigate and fix a specified project issue with verification and review.
---

Read the specified issue using the project's tracker and available tools. Follow root AGENTS.md, shared workflow guidance and applicable nested instructions. Record a bounded plan in tasks/todo.md, diagnose the cause and implement the smallest complete fix. Verify behavior with relevant tests and lint checks.

Use the git-workflow role for authorized branch/commit/PR work and the code-reviewer role for independent review. If a role is unavailable, report that limitation and use its documented guidance. A request to investigate does not authorize publication, merge or deployment. Summarize the fix, evidence and unresolved limitations.
